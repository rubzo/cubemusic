# Setup

`uv sync`

Put your `MIRLO_API_KEY` inside .env

## Running

`uv run main.py`

Type a genre from the list to play it. If you are somehow unhappy with my
superior choice of genres then edit GENRES at the top of main.py.

You get the same album all week for each genre.

Important note: all you can do is select a genre, and enjoy an album randomly
chosen in that genre.  You cannot even skip the track yet. :) But soon!
